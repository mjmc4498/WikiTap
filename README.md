# WikiTap - Traductor de Lengua de Señas

¡Bienvenido a WikiTap! Este es un sistema web accesible y funcional que permite a cualquier usuario generar una representación en lengua de señas a partir de palabras o frases escritas en lenguaje natural.

**Ver la demo en vivo:** [https://mjmc4498.github.io/WikiTap/](https://mjmc4498.github.io/WikiTap/)

## ✨ Características

*   **Traducción de Texto a Señas**: Convierte texto en una secuencia visual de señas.
*   **Biblioteca de Señas (Simulada)**: Incluye un diccionario básico de palabras comunes.
*   **Doble Vista**:
    *   **Vista General**: Muestra todas las señas de la frase a la vez.
    *   **Vista Paso a Paso**: Permite navegar entre las señas una por una, ideal para aprender.
*   **Edición de Señas**: ¿La traducción no es perfecta? Puedes hacer clic en una seña y reemplazarla por otra de la biblioteca.
*   **Texto a Voz**: Un botón para leer en voz alta el texto introducido, mejorando la accesibilidad.
*   **Diseño Accesible**: Interfaz de alto contraste, navegación simple y compatible con dispositivos móviles.

## 🚀 Cómo Usar el Sistema

Este proyecto es una aplicación web estática, por lo que no requiere instalación. Simplemente abre el archivo `index.html` en tu navegador o accede a la [demo en vivo](https://mjmc4498.github.io/WikiTap/).

**Manual de Uso:**

1.  **Introduce Texto**: Escribe una palabra o una frase en el área de texto. Por ejemplo: "hola cómo estás".
2.  **Traducir**: Haz clic en el botón **"Traducir a Señas"**.
3.  **Ver el Resultado**:
    *   Por defecto, verás todas las señas en la **Vista General**.
    *   Para verlas una por una, selecciona la opción **"Paso a Paso"** y usa los botones **"Anterior"** y **"Siguiente"**.
4.  **Editar una Seña**:
    *   Pasa el cursor sobre cualquier seña y haz clic en el ícono del lápiz (✏️).
    *   Se abrirá una ventana donde podrás seleccionar una seña diferente de la biblioteca.
    *   La traducción se actualizará automáticamente.
5.  **Leer en Voz Alta**:
    *   Haz clic en el botón **"Leer en Voz Alta 🔊"** para que el sistema lea el texto que escribiste.

## 🛠️ Cómo Desplegar en GitHub Pages

Este proyecto está listo para ser desplegado con GitHub Pages. Para activar la versión en vivo en tu repositorio, sigue estos pasos:

1.  **Fusionar el Pull Request**: Asegúrate de que los cambios de la rama `feat/sign-language-translator` estén en tu rama principal (normalmente `main` o `master`).
2.  **Activar GitHub Pages**:
    *   Ve a la página principal de tu repositorio: [https://github.com/mjmc4498/WikiTap](https://github.com/mjmc4498/WikiTap).
    *   Haz clic en la pestaña **"Settings"** (Configuración).
    *   En el menú de la izquierda, haz clic en **"Pages"**.
    *   En la sección "Build and deployment", bajo "Source", selecciona **"Deploy from a branch"**.
    *   Asegúrate de que la rama seleccionada sea tu rama principal (`main` o `master`) y la carpeta sea `/ (root)`.
    *   Haz clic en **"Save"**.

Después de unos minutos, tu sitio estará disponible en `https://mjmc4498.github.io/WikiTap`.
